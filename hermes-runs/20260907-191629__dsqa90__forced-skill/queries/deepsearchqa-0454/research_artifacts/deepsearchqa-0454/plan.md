# Research Plan: Maple Syrup Production Changes 2012-2017

## Goal
Identify maple-producing states that saw a decrease in gallons produced from 2012 to 2017 while still producing at least 1,000 gallons in 2017, using USDA NASS Census of Agriculture data.

## Components
1. **2017 Census Data** - Maple syrup production by state (gallons)
2. **2012 Census Data** - Maple syrup production by state (gallons)
3. **Comparison** - Calculate change and filter for decreases with ≥1,000 gallons in 2017
4. **Verification** - Confirm data sources and methodology

## Constraints
- Use official USDA NASS Census of Agriculture publications
- Focus on "Specialty crops" section / maple syrup tables
- Only include states with ≥1,000 gallons in 2017
- Report state names and production figures for both years

## Queries
1. **High** - Find USDA NASS 2017 Census of Agriculture maple syrup production by state table (gallons)
2. **High** - Find USDA NASS 2012 Census of Agriculture maple syrup production by state table (gallons)
3. **Medium** - Locate the specific table numbers/references for maple syrup in both census years
4. **Medium** - Verify which states are considered "maple producing states" in the census
5. **Low** - Check for any methodology changes between 2012 and 2017 that affect comparability
